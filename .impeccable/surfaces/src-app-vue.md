# Surface brief · SchedMate 周排班视图

- 范围与模式:整个应用的单一表面(顶栏 + 周页签 + 人员尺 + 7×7 网格 + 设置弹窗)。Operate:访客来排值班、解决缺口。
- 受众与任务:2–6 人小组,桌面 ~1280×800;圈定写入范围,在格子落人,处理缺口与冲突,导出。
- 关键内容/证据:真实课表 xlsx 导入;人员色;本周次数;缺口、冲突状态。
- 约束:Vue 3 + Element Plus 不换框架;本地存储;中文界面;用户绑定方向:瑞士极简(白、黑、发丝线、平色、直角、大留白、无说明文字)。
- 未决:无。

## Direction contract

THESIS:课表本身就是一张米勒-布罗克曼网格——纯白底、黑字、发丝线,平色只出现在「决定」上。它拒绝上一版纸感工作台(暖纸底、墨色、圆角、阴影、楷体余味),也拒绝后台管理的灰卡片+彩色胶囊。

OWN-WORLD:白 #FFFFFF,墨黑 #111111,发丝线 #E6E6E6,哑灰 #757575;信号红 #E30613 只给缺口与冲突。六个人员色是仅有的其余颜色,平涂、无渐变、无阴影。字体一族无衬线:Helvetica Neue / PingFang SC,数字等宽;通体 0 圆角;弹层以 1px 黑边浮起,不用投影;外边距 24px 起,8px 基线网格。

STORY:扫一眼即懂——浅色平涂是有课,实色砖是已排,红缺角是灌不过去的缺口,红框是冲突;周页签的平色填充说明一次落笔灌了多远;人员尺的数字说明本周负担。

FIRST VIEWPORT:1280×800 全见 7×7:顶栏一行 48px(词标 SchedMate 15px/700 贴左,右缘一排 16px 线性图标),其下一行周页签(等宽平格,当前周黑框),左侧 88px 人员尺(色块+名+本周数),余下全部让给网格。页面唯一的文字是标签、人名和一行状态反馈;无图例、无段落、无标题。

FORM:Operate 标准控件做直角化:按钮/弹窗/下拉沿用 Element 行为,主色换成墨黑;主动作是点格子落人,不新增任何入口。网格线横平竖直,左右贴齐外边距。

SIGNATURE:一次落笔,平色沿周页签逐格向后灌(60ms 阶梯),被课凿开的周缺一角、灌色停住。跨页面可达:设置弹窗、空态同用白底黑字直角语言。诚实风险:极简到只剩网格,初见可能显得「什么都没设计」——靠间距、线重和红点的极度纪律撑住辨识度。
